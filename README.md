# Dariabandha B1 Rules Core

Renderer-free, deterministic rules core for the approved B1 milestone. It uses dependency-free JavaScript ES modules and Node.js.

## Run the tests

```sh
npm test
```

The current suite contains 48 tests covering validation, court geometry and format profiles, fixed-tick simulation, tags, match flow, scoring, and replay inputs.

## Scope

Tasks 1–4 from the approved plan are implemented. Browser rendering, menus, AI, persistence, and online play remain outside this milestone. Smaller-format 2v2 guard placement is a documented implementation inference. See `docs/superpowers/plans/` and `.superpowers/sdd/2026-10-22-dariabandha-b1-rules-core/` for the plan, decisions, and task reports.

Files in `sources/` are read-only reference copies of the supplied master plan documents.
